CRYPTO / hard (497 pts)

The Eye

Target: dots.png (star field with hex labels), prayer.enc, and decrypt.py.

Analysis: The prompt poem corresponds to Matariki, the Maori star cluster names for the Pleiades. Eight poem lines map directly to eight stars in order (Waiti: Maia, Waita: Taygeta, Pohutukawa: Asterope, Hiwa-i-te-rangi: Celaeno, Tupuanuku: Pleione, Ururangi: Merope, Waipuna-a-rangi: Electra, Tupuarangi: Atlas). Extracting the hex labels adjacent to each star coordinates builds the 16-byte AES-128-ECB decryption key: F02E029F23582DC829F034681057B7A8.

REVERSE ENGINEERING / hard (334 pts)

Turned Around

Target: Custom esolang interpreter implementing backward execution and stack reversing.

Analysis: The binary interpreted a program that processed the flag string through alternating direction pointers and reverse stack operations. By instrumenting the state machine and following backward stack transformations, we inverted the byte permutation sequence and extracted the original key.

HARDWARE / medium (300 pts)

chip

Target: unknown-chip.png four-channel logic analyzer waveform capture with sanded labels.

Analysis: Extracted the pixel rows to recover the SPI channels: CS#, MISO, CLK, and MOSI. The master sends 0x9F (JEDEC RDID), and the responder returns EF 40 15. Manufacturer ID 0xEF indicates Winbond, and capacity 0x15 corresponds to a 16 Mbit SPI flash (W25Q16JV).

Category
hardware / logic
Protocol
SPI JEDEC RDID
Flag
bushbash{winbond, w25q16jv}

MACHINE LEARNING / medium (300 pts)

matrix_secrets

Target: PyTorch PEFT low-rank adaptation (LoRA) checkpoint with embedded secrets.

Analysis: Decomposed the low-rank projection matrices A and B in the attention layers. Computing the outer product differential between the adapter and the base model parameters revealed vector leakage storing the target flag ASCII bytes.
