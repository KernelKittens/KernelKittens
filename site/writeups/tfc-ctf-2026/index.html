Larpin (335 pts)

Points: 335 Target: Flask / Gunicorn Status: Verified Solved

Challenge Summary

A social application featuring user messaging, profile customization, and job application submission. The admin user (ID 1) holds a premium membership. Viewing premium content requires an activation token stored in window.__USER_CONFIG__.premiumToken on the admin profile.

Vulnerability Analysis

The messaging endpoint at /messages passes URL-decoded input through a custom multi-pass regex sanitizer. The sanitizer strips tags sequentially rather than recursively:

  1. First pass: removes <iframe> tags.
  2. Second pass: removes <base> tags.

By nesting tags as <if<base>rame srcdoc="..."></iframe>, the string fails the first regex check. The second pass strips <base>, assembling a valid <iframe> element that renders in the victim browser.

Bypassing CSP and Executing Payloads

The site enforces a strict Content Security Policy allowing only self-hosted scripts. However, the job portal at /jobs/1/apply permits uploading a resume as text/plain. The srcdoc attribute within our synthesized iframe imports the uploaded resume from /jobs/applications/1/cv as a script tag:

<if<base>rame srcdoc="&lt;script src=&quot;/jobs/applications/1/cv&quot;&gt;&lt;/script&gt;"></iframe>

When the admin bot reviews messages, the iframe loads, executes the JavaScript from the resume file, queries /profile/admin, extracts the premium activation token, and sends it via an automated callback message.
