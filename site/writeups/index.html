SOLVE 2026 / pwn (kernel uaf)

Slab Leaks to Root: Linux 6.6 Kernel Heap UAF

Target: Linux kernel 6.6.14 character device with KASLR, SMEP, SMAP, and kpti.

A note management ioctl failed to null freed pointers on delete. We groomed kmalloc-128 with seq_operations to defeat KASLR, manipulated msg_msg headers across message queues, and pointed modprobe_path to our payload script for root execution.

SOLVE 2026 / crypto (lattices)

Biased Nonce Recovery: Lattices vs ECDSA secp256k1

Target: Automated authentication service with a 4-bit truncated nonce RNG.

We modeled the top-zero nonce bias as an instance of the Hidden Number Problem (HNP). Constructing a 72x72 Kannan embedding matrix and running BKZ reduction in SageMath recovered the private scalar in 14 seconds.

SOLVE 2026 / reverse engineering (custom vm)

Unwinding the Yarn: Disassembling a Custom Bytecode VM

Target: x86-64 ELF binary executing obfuscated bytecode in an isolated stack machine.

Extracted the 14-opcode dispatcher loop from Ghidra and wrote an automated disassembler. Transcribed the key validation constraints into a Python Z3 solver to invert the alternating circular shifts and extract the key.

COMMUNITY / submission desk

Submit a Write-up

Anyone can submit a write-up for challenges solved in public competitions. We accept solves from team members and independent players.

Guidelines for accepted submissions:

  • Event rules must permit public write-ups (the competition must be finished).
  • Include full root-cause analysis, reproducible commands, and exploit scripts.
  • No private credentials or personal data. Only public flags and handles.

How to send your solve:

Route 1: GitHub Pull Request
Fork the repository on GitHub, add your markdown file or HTML entry under site/writeups/, and submit a PR to main.

Route 2: Direct Email
Email your write-up, solver script, and desired public credit handle to Team@kernelkittens.org with the subject [Write-up Submission] Event - Challenge Name.

All accepted community write-ups are published with full solver attribution.
