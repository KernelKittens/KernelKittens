AI Safety & Systems

1. Empirical Telemetry Findings

Analyzed: 183 Sessions Total Steps: 12,925 Tool Calls: 16,641

Behind the demos of autonomous AI swarms lies an operational reality: without rigid determinism and strict architectural boundaries, unconstrained agent swarms burn tokens, enter cyclic polling loops, and generate operational residue.

We mined session transcripts across a mixed fleet of Claude, Codex, DeepSeek Harness (DSH), and Gemini operating on live developer workstations and cloud infrastructure:

  • Cost Concentration: The median successful task completed in 20 steps. Just 3 runaway sessions (217, 164, and 156 steps) consumed 88% of total daily spend.
  • Polling Waste: 140 of 217 duplicate tool calls (64.5%) were repeated status polling loops (list_agents, wait_agent). One thread polled 15 times sequentially.
  • File Re-read Duplication: 395 reads re-fetched identical files within the same session (one file was pulled 62 times).
  • Turn Failure Rate: 23% of unconstrained agent turns ended in error, timeout, or context truncation.
Failure Analysis

2. Four Critical Production Failure Modes

A. The Polling Death Spiral

When an LLM waits for an asynchronous worker without reactive wakeup hooks, it falls back to active polling. At 200k tokens of context per step, polling burns money exponentially while consuming provider rate limits.

B. The Context Bloat Tax

A thread remaining active past 120 steps re-evaluates its entire conversation history on every turn. An agent answering a one-line question pays for 200,000 input tokens of accumulated memory.

C. The Desktop Focus Theft Glitch

On Windows workstations, child console processes spawned with standard hidden flags (-WindowStyle Hidden) still momentarily allocate a console subsystem window for ~200ms before hiding. This micro-flash steals active OS keyboard and cursor focus.

D. Recursive Cycle Deadlocks

When agents delegate freely, cycles appear: Agent A delegates to Agent B, who seeks clarification from Agent A, with no base stopping condition.

Defense Architecture

3. The Four Invariant Safeguards

To eliminate these failure modes permanently, we engineered four hard invariant rules enforced by our harness and build gates:

1. Depth Ceiling = 2
   Root -> Subagent -> Worker Leaf.
   Leaf workers are denied tool access to spawn children.

2. Circuit Breakers
   Hard cap: maximum 5 turns and $0.10 token budget per spawned child.
   Tripping either ceiling triggers an immediate partial JSON receipt.

3. Anti-Loop Hop Tracking
   AgentBus messages carry a decrementing hop_limit.
   Threads auto-abort if a recipient appears twice in a thread without progress.

4. Fleet Pause Switch
   Any agent or human can post [FLEET_PAUSE] <target>.
   Execution freezes immediately into an auditable checkpoint.
