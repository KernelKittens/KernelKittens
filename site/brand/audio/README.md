# Kernel Signal

Original ambient synth music made for Kernel Kittens. There are no samples, vocals, downloaded tracks or third-party sound recordings.

- `kernel-ambient.mp3`: 32-second seamless stereo loop for quiet, visitor-controlled site music.
- `kernel-intro.mp3`: 16-second arrangement with a 0.5-second fade in and 1-second fade out, used in the team introduction film.
- Format: 48 kHz stereo MP3, 112 kbps.
- Score: E minor, 120 BPM with a calm 60 BPM pulse; warm pads, a soft sine bass and a quiet arpeggio.

The score, oscillator definitions, stereo placement, wrapped note tails and audio mastering are reproducible with `npm run music` from `videos/`. All musical notes and waveforms are generated from that source. Browser playback controls and volume are supplied by the website.
